```markdown
# OmniAgent AI — Enterprise Multimodal AI Employee & Automation Platform

[![CI/CD Pipeline](https://github.com/enterprise/omniagent-ai/actions/workflows/ci.yml/badge.svg)](https://github.com/enterprise/omniagent-ai/actions)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.111.0-009688.svg?logo=fastapi)](https://fastapi.tiangolo.com)

[![LangGraph](https://img.shields.io/badge/Orchestrator-LangGraph-FF6F00.svg)](https://langchain-ai.github.io/langgraph/)

OmniAgent AI is a production-grade autonomous digital employee engineered to process cross-modal artifacts (PDFs, spreadsheets, machine photos, voice memos, and enterprise database records) to execute complex enterprise workflows with deterministic safety, human-in-the-loop approval gating, and immutable audit logging.

### 🌟 Key Features
- **Hierarchical LangGraph Swarm:** Supervisor Agent coordinating Vision, Document, RAG, Database, Reasoning, and Action agents.
- **Enterprise Hybrid RAG:** PostgreSQL 16 `pgvector` HNSW vector search + BM25 full-text retrieval + Cross-Encoder reranking.
- **Deterministic Risk Engine:** Risk-tiered Human-in-the-Loop approval gate (LOW: auto, MEDIUM: review, HIGH: suspended).
- **Zero-Trust Security:** Strict prompt delimiter sandboxing (`<<<UNTRUSTED_CONTENT>>>`), AST-validated SQL sandboxing, and HMAC SHA-256 tamper-proof audit trails.
- **Enterprise UI Portal:** Built with Next.js 14 App Router, TypeScript, Tailwind CSS, and Shadcn UI.
```
