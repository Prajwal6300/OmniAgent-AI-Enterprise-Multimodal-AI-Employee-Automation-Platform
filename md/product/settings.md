## 1. Enterprise Configuration Sections (`/settings`)

* **Tenant Profile:** Organization name, logo branding, and slug.
* **LLM Provider Gateways:** Encrypted API key management for Anthropic, OpenAI, Google Gemini, and local Ollama host endpoints.
* **Model Defaults:** Default model selection per task tier (e.g., Tier 1 = Claude 3.5 Sonnet).
* **Integrations Hub:** Connectors for Slack, SendGrid SMTP, Jira, SAP ERP, and PostgreSQL data warehouses.
* **RBAC User Management:** Invite enterprise team members and assign roles (`superadmin`, `admin`, `manager`, `operator`, `viewer`, `auditor`).
